# Ergon v0.1.0

Ergon v0.1.0 is the first release of the v2 runtime and authoring surface. It
consolidates the public API around object-bound benchmark definitions, moves
runtime execution onto typed graph-native task snapshots, and tightens the
dashboard around the run and experiment data needed to inspect agent behavior.

## Highlights

- Introduced the v2 object-bound authoring API for `Benchmark`, `Task`,
  `Worker`, `Sandbox`, `Evaluator`, and `Rubric` definitions.
- Rebuilt run execution around typed run-node reconstruction and canonical
  task identity.
- Added graph-native dynamic subtasks through the `WorkerContext` facade.
- Moved evaluator execution to synchronous fanout while keeping sandbox
  lifetime bounded by the worker orchestrator.
- Migrated MiniF2F, SWE-Bench Verified, ResearchRubrics, and GDPEval to the
  v2 object-bound task shape.
- Refocused the dashboard around experiments, runs, metric exploration,
  evaluation details, and operational index pages.
- Added local OpenAI-compatible model targets and a MiniF2F llama.cpp
  getting-started example.

## Authoring API

- Added object-bound public API models with typed serialization contracts and
  focused modules for workers, sandboxes, criteria, rubrics, and benchmarks.
- Added the definition writer path used to persist object-bound benchmark
  definitions and launch runs from those definitions.
- Centralized public API discriminator injection and tightened defaults around
  worker, evaluator, rubric, sandbox, and worker-context dependencies.
- Removed the transitional `TaskSpec` authoring path and compatibility bridges.

## Runtime And Evaluation

- Made run graph task identity canonical around `task_id`.
- Added run-tier task snapshots and typed task reconstruction from persisted
  graph nodes.
- Switched worker execution to typed run-node snapshots.
- Added graph-native dynamic subtasks that can be spawned from worker context.
- Kept evaluator execution on the object-bound task snapshot path.
- Added sandbox cleanup and release behavior for failed and cancelled task
  paths.
- Added runtime, identity, fanout, sandbox, and dynamic-task test coverage.

## Benchmarks And Builtins

- Reorganized built-in benchmark packages so benchmark-owned tools, criteria,
  prompts, rubrics, workers, and sandbox templates live with their domains.
- Added canonical worker modules and explicit ReAct final-output extraction.
- Replaced the private manager-backed sandbox adapter with the new E2B sandbox
  runtime and shared built-in benchmark sandbox base.
- Moved MiniF2F, SWE-Bench Verified, ResearchRubrics, and GDPEval smoke
  fixtures to the same object-bound benchmark contracts as production code.
- Added local model backends for OpenAI-compatible HTTP providers, including
  llama.cpp, with vLLM kept as a compatibility target.

## CLI And Developer Experience

- Added lifecycle and observation commands such as `ergon run status`,
  experiment-filtered run listing, experiment tags, and tag lookup.
- Completed the CLI domain migration by moving command behavior under domain
  owners and deleting the old compatibility packages.
- Added the `ergon test` CLI surface for unit, integration, smoke, dashboard,
  and real-LLM workflows.
- Moved repo scripts into importable package/test modules where practical.
- Added release-train automation and CI quality gates for Python, frontend,
  benchmark smoke tests, dashboard contracts, and release tagging.

## Dashboard

- Aligned dashboard contracts with the v2 task and definition vocabulary.
- Added generated frontend contracts for dashboard graph mutations and context
  events.
- Added experiment and run index views for denser operational navigation.
- Added experiment run metric exploration for tokens, cost, scores, duration,
  task counts, providers, and errors.
- Improved run workspace header metrics and evaluation drawer states.
- Preserved failed-run scores and nested run metrics through snapshot hydration.
- Removed stale cohort, training, models, and settings surfaces from the active
  dashboard navigation and route set.

## Examples

- Added `examples/getting_started` with a MiniF2F local llama.cpp example.
- Added shared example helpers for environment checks, launch behavior, model
  cache handling, and run observation.
- Added `ergon examples` CLI commands for listing, inspecting, checking, and
  running examples.
- Hardened example help and setup checks so lightweight environments can inspect
  examples without importing runtime-only dependencies.

## Breaking Changes

- The v2 release removes legacy registry/component catalog execution surfaces,
  saved specs, import reducer persistence, old worker/evaluator bridges, and
  `TaskSpec`.
- Runtime and dashboard vocabulary now uses canonical definition and task
  identity. Old `experiment_id`/`experimentId` and `node_id` compatibility
  surfaces were removed where they conflicted with the v2 model.
- Alembic history was collapsed to a single initial v2 migration. Treat this as
  a fresh-schema release unless you have a project-specific migration plan.
- Cohort and training dashboard routes were removed from the current active
  dashboard surface.
